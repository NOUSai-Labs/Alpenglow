# Alpenglow

**v2 is coming. v1 has been pulled.**

A major architectural upgrade is shipping in the next 48 hours.

## What's coming in v2

- **A new memory substrate** that gives agents perfect recall across a
  lifetime of interactions — on consumer hardware, with no cloud
  dependency, and no degradation as the memory grows.
- **Built-in encrypted file storage** with agent-mediated access control.
  Your files live in a vault only your agent can open, on policies you
  set.
- **On-demand format reconstruction** — drop a file in, ask your agent
  for it in any other format. Same vault, perfect fidelity.
- **Federated learning that begins on day one** for every user. The
  platform gets better the moment the first user signs up.

## Why v1 is unpublished

The v1 beta has been temporarily pulled while v2 is finalized. There is
no point starting on v1 — v2 is materially better in every dimension and
the install path will be different. Anyone who downloads v1 today would
have to migrate within days.

If you already have v1 installed, it will continue to work. We will
publish migration notes alongside the v2 release.

## How to be notified

**Watch this repo** to be notified the moment v2 ships.
